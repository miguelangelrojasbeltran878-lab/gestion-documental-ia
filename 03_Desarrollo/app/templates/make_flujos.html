Flujo Asíncrono de Procesamiento Masivo (~30 Archivos) + Síntesis con IA

Mód 1
Webhooks > Custom webhook
Recibe Manifiesto JSON con 30 URLs firmadas
Mód 2
Webhooks > Webhook response
Retorna HTTP 202 Accepted (<300 ms) sin timeout
Mód 3
Flow Control > Iterator
Desglosa el arreglo files[] (1..30)
Mód 4: Flow Control > Router (3 Rutas por Extensión)
Ruta A: .PDF y .DOCX Mód 5-6 + Resume
HTTP Get a file → OpenAI Assistants / Document OCR
Ruta B: .XLSX (Excel) Mód 7-9 + Resume
HTTP Get a file → Parse Tabular XML/CSV → OpenAI
Ruta C: .JPG / .JPEG Mód 10-11 + Resume
HTTP Get a file → OpenAI Vision (Analyze an Image)
Mód 12
Flow Control > Array aggregator
Consolida los 30 análisis en un solo JSON
Mód 13
HTTP > Make a request (Callback)
Envía POST /api/v1/lotes/callback al portal
